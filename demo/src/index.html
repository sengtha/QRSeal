A verified signature is not a reason to pay. This app never shows a green tick, because the library never returns one. A signature says a registered key produced these bytes. It says nothing about why you were asked to scan them.

Issue

Signed by this sandbox’s current issuer key, enrolled on this device’s trust list. Print the static code, or show the dynamic one on a screen; then scan it from another device that has imported this scheme, or from this one.

A static code carries no amount by rule: a printed sticker must not be given a figure the merchant did not choose. The payer enters it.

Only for documents whose life is shorter than the signing key’s: this sandbox’s keys expire in two years. A degree or a land title is outside Profile B until the specification defines archival verification.

Scan & verify

Every scan goes through the same pipeline: refuse URL carriers, route by profile and encoding, verify offline against the selected trust list, then show what the specification obliges — never a tick.

Trust

The sandbox scheme lives in this browser’s storage. Revoke the issuer key and every code it signed fails. Export the public half as a bundle and another device can verify this device’s codes — and nothing else, because the bundle carries no private key.

This is a sandbox. The Root, timestamp and issuer keys were generated in this browser and are stored in it unprotected. They protect nothing, and a code that verifies here proves nothing outside this device. Nothing on this page is issued by, endorsed by, or agreed with the National Bank of Cambodia or any other authority. KH-SQR is proposed, not adopted.
Everything runs locally: packages/core built __BUILD_DATE__, Web Crypto only; QR rendering by qrcode, decoding by the platform detector or jsQR. Source and specification at github.com/sengtha/qrseal.
