# CLAUDE.md

This repository is QRSeal: the KH-SQR signature specification for QR codes,
its reference library, CLI, Workers, conformance vectors, offline demo and
preprint. Everything an agent needs, in plain words, is in `AGENTS.md`:
what the system is, how to build a verifier or an issuer on it, the interface
rules that must not be broken, and the conventions for changing this
repository.
